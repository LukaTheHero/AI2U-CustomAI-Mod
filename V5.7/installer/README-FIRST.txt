HOW TO INSTALL (the easy way)

1. Extract this whole zip anywhere (Desktop is fine).
   IMPORTANT: actually extract it - don't run things from
   inside the zip preview window.

2. Double-click Install.bat

3. Follow the messages. It will:
   - find every copy of AI2U on your PC, show them all, and pick
     the one that last ran with mods - then WAIT for you to
     confirm that folder. Press Enter to install there, type
     another copy's number, B to browse for a folder, or paste
     a folder path. Play more than one copy? Run it once each.
   - download and set up BepInEx if you don't have it
   - install the mod
   - check that everything landed where it should

4. Start the game and press F9 to set up your API key.

If anything goes wrong it stops BEFORE changing things and
tells you what to fix in plain English. If you're stuck, join
the Discord and paste the whole installer window.

Nothing outside your game folder is ever touched, and any file
it replaces is backed up next to itself first.
